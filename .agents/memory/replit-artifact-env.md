---
name: Replit artifact environment
description: متغيرات البيئة التي تحتاجها عمليات بناء ومعاينة خدمات Replit المُدارة
---

خدمات artifact المُدارة تضخ `PORT` و`BASE_PATH` تلقائيًا أثناء التشغيل. أما أوامر Vite اليدوية خارج workflow فتحتاج تمريرهما صراحة، وإلا يفشل تحميل إعداد Vite قبل بدء البناء.

**Why:** إعدادات الواجهة وCanvas تتحقق عمدًا من وجود المتغيرين، والبناء العام خارج workflow فشل عندما لم يكونا موجودين.

**How to apply:** استخدم workflow المُدار للتشغيل والمعاينة. عند تنفيذ build يدوي، مرّر `PORT` و`BASE_PATH` المطابقين لخدمة artifact.
